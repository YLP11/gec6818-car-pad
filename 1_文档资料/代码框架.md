# 代码框架

> GEC6818 车载娱乐小平板：纯 C + framebuffer 直绘，无 GUI 库。
> 交叉编译 arm-linux-gcc 5.4.0，链接 `-lpthread -lm`。

## 一、概述

**main.c 一个 while(1) 套两个阻塞式页面（登录页、主界面），每个页面内部再套自己的"贴图 → 取触摸 → 判坐标 → 重绘"循环；绘制走 framebuffer，触摸走 input 子系统，音视频解码交给 madplay / mplayer 子进程，用 PID + 信号精确控制。**

## 二、目录结构

```
2_程序资料/
├── src/            12 个源文件
├── inc/            对应头文件（宏定义 + 函数声明）
├── log/            日志模块 log.c / log.h
├── res/            界面资源图（启动/主界面/相册/音乐/视频/游戏）
└── build/          CMake 构建产物
```

## 三、启动流程（main.c）

```c
int main(void)
{
    Log_Init();                        // 打开 /root/car/log/log.txt（目录不存在自动 mkdir）
    create_lcd("/dev/fb0");            // open + mmap 显存
    Touch_Init();                      // 打开触摸设备
    f = fontLoad("simfang.ttf");       // 加载字库（全局指针，画中文用）
    Show_Open("/mnt/sd/car/open_su7"); // 开机动画：逐帧贴图

    while (1) {
        Login_Register();              // 登录页：成功才返回
        Main_UI();                     // 主界面：返回 = 用户点了登出
    }                                  // 循环 = 登录 → 主界面 → 登出 → 再登录
}
```

整个程序的生命周期就是这一个循环，不需要状态机。

## 四、模块详解（按调用层次从上到下）

### 1. login.c —— 登录注册 + 屏幕键盘

| 函数 | 职责 |
|---|---|
| `User_Register(name, pwd)` | 注册校验：重名返回 -1，成功追加写入板端 `user.txt` |
| `User_Login(name, pwd)` | 登录校验：打开 user.txt 逐行比对，匹配返回 0 |
| `Login_Register()` | 登录页主循环：贴背景图 → get_xy 取点击 → 分发 |
| `Page_Register()` | 注册页主循环，逻辑与登录页一致 |
| `Keyboard_Input()` | 软键盘输入循环：绘制键盘 → 判断按键 → 字符追加到缓冲区 |
| `Keyboard_Show(page)` | 绘制某一页键盘（字母大写/小写/数字符号） |
| `Toast_Show()` | 弹提示图（登录成功/密码错误/重名等，白胶囊绿对勾风格） |

**细节**：触摸屏有 7~8px 偏差，按键判定做两级匹配——先精确匹配按键区域，未命中则在 12px 扩展区找中心最近的键（"123" 切数字键盘不灵就是这么修的）。

### 2. ui_main.c —— 主界面

| 函数 | 职责 |
|---|---|
| `Main_UI()` | 主循环：启动时间线程 → 贴图 → get_slide → 左右滑切卡片 / 点击进功能 / 登出 / 关机 |
| `Main_Show(focus)` | 整页重绘：背景 + 顶栏 + 角落图标 + 4 张卡片；卡片 x 坐标 = `CARD_CX + (i-focus)*间距`，滑动只改 focus，越界部分用 `Show_Part_Bmp` 截断 |
| `Time_Thread()` | 时间线程：每秒 `Show_Time()` 刷新顶部日期时间 |
| `Confirm_Box(img)` | 二次确认框（登出/关机/删照片共用）：确认返回 1，取消/框外返回 0 |
| `Show_Time()` | localtime 取时间 → Lcd_DrawText 画在顶部横栏 |

**关机流程**：确认后 `pthread_cancel + join` 停时间线程（防动画期间盖时间条闪烁）→ `killall madplay mplayer` → mplayer 全屏播 4 秒关机动画 → 显存清零 → `kill(getpid(), SIGKILL)`，程序不回主界面。

### 3. album.c —— 电子相册

| 函数 | 职责 |
|---|---|
| `Album_UI()` | 网格页主循环：滑动翻页 / 点缩略图进大图 / 返回 |
| `Scan_Photos()` | 扫描 photo 目录，按文件名数字去重排序，填 full/thumb 数组 |
| `Thumb_Path()` | 由大图名推导缩略图名，自动兼容补零/不补零两种命名 |
| `Album_Show(scroll)` | 网格重绘：3×3 缩略图 + 页码 |
| `Photo_View(idx)` | 大图页循环：< > 切换（按下点判定）、删除、设壁纸 |
| `Del_Confirm()` | 删除二次确认，确认后 remove 大图+缩略图并重扫 |
| `Copy_File()` | 设为壁纸：复制到指定路径 |
| `Num_Key()` | 从文件名提取数字编号（去前导零），用于排序去重 |

### 4. media.c —— 音乐 + 视频（多进程核心）

**音乐部分**：

| 函数 | 职责 |
|---|---|
| `Music_UI()` | 播放页循环：底部三键（上一首/播放暂停/下一首）+ 左右滑切歌 |
| `Play(i)` | `popen("madplay x.mp3 >/dev/null 2>&1 & echo $!")` 启动子进程并记录 PID |
| `Toggle()` | 播放/暂停：`kill(pid, SIGSTOP/SIGCONT)`，内核级冻结无法忽略；PID 异常时退回 killall 数字信号 |
| `Switch(i)` | 切歌：Stop + 换编号，**不自动播放**，点播放键才出声 |
| `Stop()` | `kill(pid, SIGKILL)` + killall 双保险，清状态 |
| `Show_Page()` | 整页重绘：播放中贴 play 图，否则贴 pause 图 |

**视频部分**（与音乐同构）：

| 函数 | 职责 |
|---|---|
| `Video_UI()` / `List_Show()` | 列表页：缩略图卡片 + 片名，点开播放 |
| `Play_Page(i)` | 全屏播放页：点按暂停弹菜单（继续/退出），左滑重播 |
| `Player_Start(i)` | `popen` 启动 mplayer（`-vo fbdev -loop 0` 直写显存）并记录 PID |
| `Player_Pause(pause)` | SIGSTOP / SIGCONT |
| `Player_Stop()` | SIGKILL + killall |

### 5. game.c —— 游戏中心

| 函数 | 职责 |
|---|---|
| `Game_UI()` | 游戏中心菜单：五子棋 / 贪吃蛇两个入口 |
| `Gomoku_UI()` | 五子棋主循环：点击 → 换算最近交叉点 → 落子 → `Check_Win` 判五连 → 胜利横幅；结束后点屏幕重开 |
| `Gomoku_Show(over, turn)` | 棋盘绘制：画线 + 棋子贴图（带光泽 BMP） |
| `Snake_UI()` | 贪吃蛇主控：创建触摸线程，主线程计时驱动移动 |
| `Snake_Touch()` | 触摸线程：收四向滑动改方向，点按切暂停 |
| `Snake_Step()` | 蛇走一步：吃食物加分、撞墙/撞己结束 |
| `Snake_Draw()` / `Snake_Reset()` | 绘制（含暂停图/结束横幅）/ 状态重置 |
| `Hit_Back()` / `Hit_Snake()` | 返回热区判定（90×60，避开电阻屏贴边盲区） |

### 6. 支撑层

**bmp.c —— 贴图**

| 函数 | 职责 |
|---|---|
| `Show_Bmp(path)` | 整屏贴图（800×480） |
| `Show_Any_Bmp(path, w, h, x, y)` | 任意位置任意尺寸贴图（提示框/横幅/棋子） |
| `Show_Part_Bmp(...)` | 局部贴图：从图片 (sx,sy) 起取 sw×sh 贴到屏幕——主界面卡片越界截断就靠它 |
| `Show_Icon(...)` | 小图标贴图 |
| `Show_Open(dir)` | 逐帧贴目录里的图片 = 开机动画 |
| `Lcd_DrawText(...)` | 字库渲染到画布再贴屏（画布色格式 `0xRRGGBB00`） |

**lcddev.c —— 显存与绘图**

| 函数 | 职责 |
|---|---|
| `create_lcd(devname)` | open `/dev/fb0` + mmap，保存设备指针（全局） |
| `draw_point / draw_line_c / draw_fill_circle / draw_fill_tri / draw_rect` | 基础图元（棋盘线、顶栏、箭头都靠它们） |
| `draw_rgb(x, y, rgb, w, h)` | 把 BMP 解码后的像素块逐行拷入显存（贴图的最后一步） |

**touch.c —— 触摸**

| 函数 | 职责 |
|---|---|
| `Touch_Init()` | 打开 `/dev/input/event0` |
| `get_xy(&tx, &ty)` | 阻塞取一次点击坐标（键盘用） |
| `get_slide(&x0,&y0,&x1,&y1)` | 阻塞取一次完整手势：按下点 + 抬起点（页面用）；坐标无条件累积，按下事件到时取最新坐标当起点，快速双击沿用上次坐标兜底 |

**font.c / truetype.c**：课程提供的 TTF 解析库（`fontLoad / fontSetSize / fontDrawUTF8`），不做修改。

**log/log.c —— 日志**（rxi/log.c，MIT）

- 6 级：TRACE / DEBUG / INFO / WARN / ERROR / FATAL，项目用 `LOG_INFO` 过滤
- `log_add_fp(fp, level)` 把日志写入 `/root/car/log/log.txt`（追加）
- `log_set_lock` 挂 pthread 互斥锁，多线程并发写不交错
- 格式：`2026-11-24 09:35:40 INFO  login.c:181: 登录成功:ylp`

## 五、线程 / 进程模型

```
主进程 a.out
├── 主线程        界面绘制 + 触摸循环（每个页面一个 while）
├── 时间线程      每秒刷时钟（Main_UI 创建，登出/关机时 cancel+join 回收）
├── 贪吃蛇触摸线程 收滑动手势（Snake_UI 创建，退出回收）
├── madplay 子进程  MP3 解码 → 声卡（popen 启动，记 PID）
└── mplayer 子进程  视频解码 → framebuffer（popen 启动，记 PID）

子进程控制：kill(pid, SIGSTOP 暂停 / SIGCONT 继续 / SIGKILL 停止)
不按名字 killall：busybox 实现不可靠，曾有残留双实例互相干扰
```

## 六、关键约定

1. **按钮判定一律用按下点 (x0,y0)**：快速点按时抬起点失真（甚至报 (0,0)），按下点稳定
2. **热区避开屏幕边缘 60px**：电阻屏贴边失灵，热区宁可加宽
3. **BMP 宽度必须 4 的倍数**：BMP 行按 4 字节对齐，否则花屏
4. **两套颜色格式不可混用**：draw_rect 用 `0x00RRGGBB`；Lcd_DrawText 画布/字体色用 `0xRRGGBB00`
5. **日志写板子路径** `/root/car/log/log.txt`，程序自动建目录
